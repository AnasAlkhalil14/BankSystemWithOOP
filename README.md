# 🏦 Bank Management System (OOP)

A console-based **Bank Management System** implemented in **C++** using **Object-Oriented Programming principles**.
The system simulates real banking operations such as managing clients, users, transactions, and currency exchange.

---

# 📌 Features

### 👥 Client Management

* Add new clients
* Update client information
* Delete clients
* List all clients
* Find a client

### 👤 User Management

* Add new users
* Update users
* Delete users
* Manage user permissions

### 💰 Transactions

* Deposit money
* Withdraw money
* Transfer between accounts
* View total balances
* View transfer logs

### 💱 Currency Exchange

* List currencies
* Find currency
* Currency calculator
* Update exchange rates

### 🔐 Authentication

* Login system
* Login register history

---
